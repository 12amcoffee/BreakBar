BreakBar interactive preview

A menu bar Pomodoro timer for macOS with fully custom intervals and a Rest window that waits for you. Hover, click and type: everything below responds the way the app does.

Download BreakBar View on GitHub

This page is a design preview built from mock-ups, so it shows the looks and behaviour but is not the app itself. BreakBar needs macOS 13 or later.

The dropdown

Work, short rest and long rest sit under the Start button. Click a pill to open its stepper. The number looks like plain text until you hover it; click it to type a value, then press Return (Esc cancels).

Settings

The same warm surfaces. Numbers can be typed here too: hover one, click it and type. Switches and sliders use the tomato accent; the steppers stay grey because macOS draws them itself.

The Rest and Start working windows

Four styles, chosen in Settings. One switch changes every mock-up below. Waiting to rest is the Rest window. Resting is what it becomes after you click Start resting. Break is over is the Start working window.

1 · Small floating window

Click Close to dismiss it. It never takes the keyboard from whatever you are typing.

2 · Maximised floating window

Nearly full screen, with the menu bar and Dock still visible. Return starts the rest (or the work), Esc or Close dismisses it, and focus goes back to the app you were using.

3 · Notification-style banner

Slides in at the top right. Click × to dismiss it; it never takes the keyboard.

4 · Full-screen overlay

A tomato screen in light mode and an ink screen in dark mode. Esc or Close (Esc) dismisses it. Open either one at full size on your screen.
